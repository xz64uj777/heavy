# Helios Heavy v10

Android-first 2D heavy-lift launch simulator (Falcon / Helios Heavy career sim). Career missions, autopilot, coach, projected path, booster recovery.

**Player CLEAR** build: upper-only Light, `deployTimer`, `nearApo`.

## Play

Open the live web build. Phone Back pauses. The game saves if you leave and resume later.

```
npm install
npm run dev
```

Hangar / APP_NAME: **Helios Heavy v10**.
